## What it checks

`databricks` isn't on the PATH.

## Why

Mason deploys through the Databricks CLI. It isn't installed, or isn't on the PATH of the shell that ran Mason, such as a CI job.

## Example

The Databricks CLI isn't installed. In a project, this fails:

```console
$ mason deploy --env dev
```

## Fix

Install the Databricks CLI and put `databricks` on your PATH. `databricks --version` checks it.
