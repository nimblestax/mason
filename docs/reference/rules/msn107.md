## What it checks

A config file is missing, isn't valid YAML or isn't a mapping, or a Seed's file isn't valid CSV.

## Why

Mason reads a file before it checks anything in it. A file it can't read can't be checked at all.

## Example

Write this file into the project `mason init` creates, and `mason validate` fails:

`domains/sales/sources/orders.yaml`:

```yaml
kind: source
version: 1
path: /Volumes/{env}_sales/bronze/landing/orders
format: [json
```

## Fix

Correct the YAML at the line the diagnostic gives, and make the file a mapping of fields that starts with `kind`. For a Seed's file, save it as UTF-8 and close every quoted value.
