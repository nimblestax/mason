## What it checks

A Gold Model reads files or external data, such as `read_files(...)` or ``parquet.`/path` ``, instead of a table.

## Why

A Gold Model reads tables in the project. Data read straight from files skips bronze and silver, so it isn't landed, typed or checked, and Mason can't point the path at each Environment.

## Example

Write this file into the project `mason init` creates, and `mason validate` fails:

`domains/sales/models/fct_orders.sql`:

```sql
SELECT order_id, amount
FROM read_files('/Volumes/prod_sales/bronze/landing/orders')
```

## Fix

Declare a Source for these files, and read its silver table by Logical Name.

## Principle

This Rule enforces [Data flows one way](https://nimblestax.com/way/data-flows-one-way), from the Nimblestax Way.
