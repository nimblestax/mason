## What it checks

`--env` isn't an Environment in the project.

## Why

Environments are declared in `mason.platform.yaml`, each with its workspace. An Environment that isn't there has no workspace or catalogs to compile or deploy for.

## Example

In a project, this fails:

```console
$ mason compile --env staging
```

## Fix

Use an Environment from `mason.platform.yaml`, which the diagnostic lists, or add the Environment there.
