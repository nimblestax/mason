## What it checks

A Gold Model's SQL doesn't parse as one Databricks SQL query.

## Why

Mason reads a Gold Model's SQL to find every table it reads, so it can check them, build them first and point each at the right Environment. SQL it can't parse hides those reads. A file with more than one statement is reported too, because a Gold Model is one query.

## Example

Write this file into the project `mason init` creates, and `mason validate` fails:

`domains/sales/models/fct_orders.sql`:

```sql
SELECT order_id, amount
FROM sales.silver.orders
WHERE
```

## Fix

Make the file one Databricks SQL query that runs on its own.
