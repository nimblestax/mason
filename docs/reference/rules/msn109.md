## What it checks

A model names a SQL file that doesn't exist.

## Why

A Gold Model's config names the SQL that builds its table. Without that file there is nothing to build.

## Example

Write this file into the project `mason init` creates, and `mason validate` fails:

`domains/sales/models/fct_returns.yaml`:

```yaml
kind: model
version: 1
sql: fct_returns.sql
```

## Fix

Correct `sql`, or add the SQL file to the same folder.
