## What it checks

A config file has no `kind`.

## Why

`kind` says what a file declares, such as a Source or a Gold Model, and so which fields it may have. Without it, Mason can't check the rest of the file.

## Example

Write this file into the project `mason init` creates, and `mason validate` fails:

`domains/sales/sources/orders.yaml`:

```yaml
version: 1
path: /Volumes/{env}_sales/bronze/landing/orders
format: json
```

## Fix

Add `kind` at the top of the file, naming the Kind its folder holds: `source` in `sources/`, `seed` in `seeds/` and `model` in `models/`.
