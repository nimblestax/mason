## What it checks

A Seed's column has a type Mason can't check values against.

## Why

Mason checks every value in a Seed against its column's type. A type it can't check, often a misspelt one, would let any value through.

## Example

Write these files into the project `mason init` creates, and `mason validate` fails:

`domains/sales/seeds/countries.yaml`:

```yaml
kind: seed
version: 1
file: countries.csv
columns:
  code: VARCAHR
```

`domains/sales/seeds/countries.csv`:

```csv
code
AU
```

## Fix

Use a type Mason checks, which the diagnostic lists, such as `STRING`, `INT`, `DATE` or `DECIMAL(10, 2)`.
