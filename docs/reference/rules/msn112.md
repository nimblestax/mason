## What it checks

A Seed's `file` doesn't exist beside it.

## Why

A Seed is a small table kept in the repo as a CSV file and a config file. Without the CSV file there is no data to load.

## Example

Write this file into the project `mason init` creates, and `mason validate` fails:

`domains/sales/seeds/countries.yaml`:

```yaml
kind: seed
version: 1
file: countries.csv
columns:
  code: STRING
```

## Fix

Correct `file`, or add the CSV file to the same folder.
