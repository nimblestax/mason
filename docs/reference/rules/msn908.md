## What it checks

The refresh failed with another pipeline error. The message is the pipeline's own.

## Why

`mason deploy` refreshes an Environment's tables after it ships them. When a pipeline update fails for a reason Mason has no Rule for, it reports the pipeline's own error, read from its event log, rather than a generic failure.

## Example

The pipeline can't read the Volume a Source's files land in. In a project, this fails:

```console
$ mason deploy --env dev
```

## Fix

Fix the cause, then deploy again. The pipeline's event log in the workspace has more.
