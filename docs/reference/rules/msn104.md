## What it checks

This Mason doesn't support that `version`.

## Why

The file is written against a schema this Mason doesn't have, usually because a newer Mason wrote it. Checking it against another version's schema would give wrong answers.

## Example

Write this file into the project `mason init` creates, and `mason validate` fails:

`domains/sales/sources/orders.yaml`:

```yaml
kind: source
version: 2
path: /Volumes/{env}_sales/bronze/landing/orders
format: json
```

## Fix

Use a version this Mason supports, which the diagnostic lists. If the file needs a newer Mason, upgrade Mason in the project so everyone runs the same one.
