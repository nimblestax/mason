## What it checks

SQL builds a table name when it runs, such as `IDENTIFIER(...)`, so Mason can't see what it reads.

## Why

Mason checks every table a Gold Model reads, and shows those reads in review. A name built when the query runs can't be seen until then, so it could read any table in any Environment.

## Example

Write this file into the project `mason init` creates, and `mason validate` fails:

`domains/sales/models/fct_orders.sql`:

```sql
SELECT order_id, amount
FROM IDENTIFIER(:orders_table)
```

## Fix

Write the table as a Logical Name, such as `sales.silver.orders`.
