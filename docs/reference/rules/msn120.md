## What it checks

Two config files share a name in one folder, such as `orders.yaml` and `orders.yml`. Mason reads either ending, and writes `.yaml`.

## Why

A config file's name is its table's name, so two files with one name would declare one table twice, and Mason can't tell which one is meant.

## Example

Write this file into the project `mason init` creates, and `mason validate` fails:

`domains/sales/sources/orders.yml`:

```yaml
kind: source
version: 1
path: /Volumes/{env}_sales/bronze/landing/orders
format: json
```

## Fix

Keep one of the files, and delete or rename the other.
