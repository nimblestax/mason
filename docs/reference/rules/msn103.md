## What it checks

A config file has no `version`.

## Why

A Kind's schema can change between Mason releases. `version` says which schema a file is written against, so a newer Mason reads an older file as it was meant.

## Example

Write this file into the project `mason init` creates, and `mason validate` fails:

`domains/sales/sources/orders.yaml`:

```yaml
kind: source
path: /Volumes/{env}_sales/bronze/landing/orders
format: json
```

## Fix

Add `version` below `kind`, with the latest version this Mason supports, such as `version: 1`.
