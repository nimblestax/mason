## What it checks

A Databricks CLI command failed.

## Why

Mason ran a Databricks CLI command, such as `databricks bundle deploy`, and it failed. Its log on stderr says why, often authentication, permissions or the workspace itself. A refresh that fails reports this Rule too when Mason can't read the pipeline's own error.

## Example

The Databricks CLI isn't signed in to the dev workspace. In a project, this fails:

```console
$ mason deploy --env dev
```

## Fix

Read the Databricks CLI's log on stderr, fix what it names, and run the command again. `databricks auth describe` checks how the CLI signs in.
