## What it checks

The command line is wrong.

## Why

A command, option or argument is unknown or missing. With `--json`, Mason still prints one envelope, so a script or agent reads the problem instead of help text. It exits 2, because the command line needs a change, not the project.

## Example

In a project, this fails:

```console
$ mason validate --projct .
```

## Fix

Correct the command line. `mason <command> --help` lists a command's options.
