## What it checks

A Seed and a Source in one Domain share a name, so they would be one table.

## Why

A Seed's table is in silver, beside each Source's silver table. A Seed and a Source with one name in one Domain would write the same table, and one would overwrite the other.

## Example

Write these files into the project `mason init` creates, and `mason validate` fails:

`domains/sales/seeds/orders.yaml`:

```yaml
kind: seed
version: 1
file: orders.csv
columns:
  order_id: INT
```

`domains/sales/seeds/orders.csv`:

```csv
order_id
1
```

## Fix

Rename the Seed or the Source, so each has its own table.
