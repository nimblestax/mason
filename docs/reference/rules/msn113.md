## What it checks

The first line of a Seed's file doesn't name each declared column once.

## Why

Mason matches a Seed's values to its columns by the names on the first line, then checks each value against its column's type. A first line that doesn't name each column once leaves values with no column, or a column with no values.

## Example

Write these files into the project `mason init` creates, and `mason validate` fails:

`domains/sales/seeds/countries.yaml`:

```yaml
kind: seed
version: 1
file: countries.csv
columns:
  code: STRING
```

`domains/sales/seeds/countries.csv`:

```csv
country
AU
```

## Fix

Make the first line name each declared column once, or change `columns` in the Seed's config file.
