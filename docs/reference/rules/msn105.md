## What it checks

A file's `kind` doesn't belong in its location.

## Why

Where a file lives says what it is: Sources in `sources/`, Seeds in `seeds/` and Gold Models in `models/`. When a file's `kind` disagrees with its folder, Mason can't tell which is right, so it doesn't guess.

## Example

Write this file into the project `mason init` creates, and `mason validate` fails:

`domains/sales/sources/orders.yaml`:

```yaml
kind: model
version: 1
path: /Volumes/{env}_sales/bronze/landing/orders
format: json
```

## Fix

Change `kind` to the Kind its folder holds, or move the file to the folder for its Kind.
