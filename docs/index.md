Mason brings the software development lifecycle to Databricks pipelines. A pipeline is YAML and SQL in your repo, from bronze to gold. Mason checks it with no workspace, compiles it for each Environment, and deploys it, so every change is reviewed in a pull request, tested, and promoted from dev to prod.

## Where to start

- **Get started** installs Mason and walks a Source through to gold.
- **Concepts** explains how Mason thinks: Domains and Layers, Logical Names, Environments and Deferral.
- **Guides** take one task at a time, such as adding a Source.
- **Reference** lists every Kind, command and Rule. If you're scripting Mason, start with [JSON output](reference/json-output.md).
